# Transcript To Markdown

This is a Claude Code skill (`/transcript-to-markdown <path-to-transcript-file>`) for turning a text-based transcript — a meeting recording transcript, notes, or chat log — into a structured Markdown document written next to the input file: it reads the transcript, asks whether to produce Meeting Minutes or an Architecture Decision Record (ADR) and whether the output should be in English or German, then fills the matching ready-made template (`template-meeting-minutes.md` / `template-meeting-minutes-de.md` / `template-adr-en.md` / `template-adr-de.md`) with content derived from the transcript, keeping that template's exact section structure. The Meeting Minutes templates cover topic, decisions, action items (with owner and due date), and open questions; the ADR templates follow a Status/Context/Options/Recommendation/Decision/Consequences/Author structure. The result is written as `<input-file-basename>-minutes.md` or `<input-file-basename>-adr.md` in the same directory as the input file.
