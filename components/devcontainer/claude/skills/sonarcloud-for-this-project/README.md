# SonarCloud For This Project

This is a Claude Code skill (`/sonarcloud-for-this-project`) for inspecting the SonarCloud project bound to the current git repository directly from inside the devcontainer, without MCP: it reads `SONARCLOUD_TOKEN`, `SONARQUBE_URL` and `SONARQUBE_ORGANIZATION` from the environment (as set by `.devcontainer/devcontainer.json`), derives the SonarCloud project key from the git `origin` remote, and calls a fixed set of ready-to-use `curl`/`jq` scripts in `scripts/` (quality gate, measures, issues, security hotspots, duplications, rules, analysis history, measure history, background-task activity, and the file tree) against the SonarCloud Web API — so Claude never has to rediscover how to authenticate or which endpoints to use, and only the relevant script's output is read into context. Invoke it with an argument telling it what to check, e.g. `/sonarcloud-for-this-project issues`, `/sonarcloud-for-this-project coverage`, or `/sonarcloud-for-this-project quality-gate`; see `SKILL.md` for the full argument-to-script mapping. If the required environment variables are missing or the token is rejected, the skill aborts with a clear error instead of trying to work around it.
